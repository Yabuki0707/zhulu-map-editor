# 地图编辑器（模块版）

《逐鹿》栅格底图的编辑工具。**栅格是全图唯一几何真源**，一一映射：每个像元恰好一条记录
（**地块编码** + **块区编码** + **地形编码** + **气候编码**）。

**编辑器只产出行政图**（地块 / 块区 / 地域）；**地形图与气候图由管线定稿、编辑器只读**
（`docs/adr/0001`）。只读自然层的全部知识收在 `js/ro.js` 的一张表里（见下）。

## 打开

**只有一份产物**：双击 `启动编辑器.bat` —— 它起本地服务 `serve.py` 再开浏览器。
ES 模块在 `file://` 下会被 CORS 拦，且浏览器会缓存旧 js，所以必须走这个带 `no-store` 的服务。
（早先还有个"单文件版" `../栅格编辑器.html`（把 js 与数据内联成 base64，双击即开）；
两份必然分叉，已按需求方指令整条删除，连打包工具一起。）

这个服务**不再是纯静态**（`docs/adr/0002`）——图的真源只有一处，编辑器不持有副本：

| 网址 | 给谁 |
|---|---|
| `/数据/<文件>` | `地图/地图数据/栅格/`（**唯一真源**） |
| `/草稿/<文件>` | `地图/待合入/`（编辑器存的草稿） |
| `POST /保存` | 只允许写 `地块编码.png` / `分区编码.png` / `台账.json` 三个文件，一律落进 `地图/待合入/` |

服务根仍是 `地图编辑器/`，所以网址依然是 `/index.html`——是**虚拟路径映射**，不是把服务根上移。

## 改完的东西怎么进项目

编辑器的产出**不直接写真源**，走两步：

1. 编辑器里 `⋯ → 存到待合入目录` → 三件落进 `地图/待合入/`；
2. `python tools/import_editor.py` → 校验（指纹 / 地块不压海洋 / 块区不越界 / 编号不重复）
   → **备份** → 合入真源 → 重写 `js/data.js`。

`import_editor.py --dry-run` 只校验不写。合入前必定备份到
`地图/待合入/备份-<时间戳>/`，回滚 = 把那四个文件拷回原位。

启动时若 `待合入/` 里有草稿，编辑器会**问**：用草稿继续，还是从正式版开始。
（草稿里只有行政图两层；地形与参考顶点**永远**读真源。）

> 另外还有一条 `⋯ → 保存进度`（`Ctrl+S`）：那是浏览器 localStorage 的**增量**存档，
> 只为防浏览器崩溃丢工作，**不是产出**。两条路各司其职，都在。


## 三个可编辑单元 + 四个只读自然层 × 两种模式

**视图**（`V`）与**编辑**（`E`）分开。顶栏那一排是**单元**：三个可编辑的（行政图）＋
只在视图模式出现的**只读自然层**（**样式 / 覆盖 / 形态 / 气候**）。

| 单元 | 键 | 底图着色 | 编辑对象 | 笔刷行为 |
|---|---|---|---|---|
| **地域** | `1` | 按地域色（未指派半透明，地形透出） | **地块** | 拖过一片地块即改其地域归属（改元数据，不动像元） |
| **地块** | `2` | 按**相邻必不同**的调色板（12 色，相邻地块一定不同色） | **栅格** | 把当前地块编码写进像元 |
| **块区** | `3` | 地块着色 + 块区着色压在上层 | **所属地块内的栅格** | 只在块区"所属地块"的范围内写入块区编码 |
| **样式** | `4` | **按显示类着色**（覆盖 × 形态 × 气候 三条轴合成出来的名字与颜色，88 类） | **（只读）** | **没有笔刷**——管线定稿（见下） |
| **覆盖** | `5` | 按**覆盖码**着色（20 类：海洋/淡湖/密林/草原/沙质裸地…；只看**地表是什么**） | **（只读）** | **没有笔刷**——同上 |
| **形态** | `6` | 按**形态码**着色（4 类：平原/丘陵/高原/山地；只看**平陡**） | **（只读）** | **没有笔刷**——同上 |
| **气候** | `7` | 热量带定色相 × 干湿定浓淡 | **（只读）** | **没有笔刷**——同上 |

> **「样式」与「覆盖」＝需求方要的"覆盖与样式两种模式"**；「形态」「气候」是另外两根轴的
> 单轴视图。这一层原来叫**「地形」**（2026-10-10 改名「样式」）：**地形是那三个轴本身，
> 样式是它们合成出来的样子**——`k` 仍是 `"terrain"`，所以本地存档与键盘 `4` 号位没变。

- **视图模式**：拖拽平移 · 滚轮缩放 · 点选（悬停贴片报覆盖／形态／热量带／干湿／显示类）。
- **编辑模式**：左键涂抹 · **右键 = 选中**（按住可连续拾取）· `空格`/中键平移 · 笔刷圆形并在地图上画范围圈。
  **编辑模式下单元条上根本没有自然层**——四个只读按钮连同分隔符一起隐藏；按 `4`–`7` 会提示去视图模式，
  存档若停在它们上面，回编辑模式会自动落到「地块」。

## 笔与橡皮

- 顶栏的**笔/橡皮开关**是 SVG 图标（笔尖 / 橡皮），也可按 `B` / `X` 切换；
  橡皮 = 清掉当前单元的对象（地块 → 0；块区 → 0；地域 → 未指派）。只读自然层没有笔，也没有橡皮。
- **半径 1–50 格**（上限 50 格 ≈ 415 km）：顶栏 SVG 滑杆拖动，`[` `]` 微调，
  数值实时显示；半径 1 = 单格，半径 2 = 3×3，圆内才落笔。
- 拖拽时按半径自动补点插值，快速划过也不断线；一次拖拽 = 一步撤销。

## 块区（dist 层）

地块之下再分一层"块区"，用来表达一地块内的港口/关隘/郡治片区等：

- `＋ 新建` 建块区后，**第一笔落在地块上时自动认领该地块**（也可在右栏手选"所属地块"）。
- 只允许在所属地块的范围内绘制；涂到别的地块上会被拒绝。
- 右栏可查"越界像元"数（地块被重新划分后可能残留），有 `修正越界` 一键清掉。

## 只读自然层（样式 / 覆盖 / 形态 / 气候）：一张表说了算

**自然层 = 管线定稿**（`docs/adr/0001`）。地形是 `ETOPO 高程 ＋ Copernicus LC100 土地覆盖`
算出来的、气候是柯本分出来的，将来都要做规则层的来源（如「基础地形代价」）——让人用笔刷
随手改模拟底数，一笔划过就会静默改掉行军耗时。所以编辑器里它们**只读**。

**一层的全部知识都在 `js/ro.js` 的 `RO_LAYERS` 里**（2026-10-09 抽的）：

```js
terrain: { k, n, tip, title, sub,        // 单元元数据（按钮由它生成）
           rgb(字节, 气候码),             // 一格的取色 —— 满分辨率画布与金字塔都走它
           bucket / oceanBucket / bucketCount / bucketLabel,   // 统计"一格记进哪个桶"
           panel(stats), legendNote(), insp(stats), note(stats) }
```

- 载入时 `registerUnits()` 把它注册进 `config.js` 的单元表，于是**顶栏按钮、左栏面板、
  右栏检视器、底图取色全由它派生**——加第三层只在这张表里加一条，`config/ui/raster` 一行不动。
- 面板与检视器共用**同一份统计**：一次遍历（944 万格）喂所有层，缓存 600 ms。海洋要不要算
  **由各层自己答**（`oceanBucket()`）：样式层要——海洋是一类显示类（占全图 68.31%），
  少了它图例与页脚读数对不上；形态层与气候层不要——**海洋与海冰（覆盖 16）那两位都是
  don't-care**，混进来会让"平原"多出 645 万＋72.6 万格、"寒带"多出同样多。判据统一在
  `ro.js` 的 `noAxis()`，别在层描述里各写一遍 `>> 3 === 0`（海冰会被漏掉）。
- 拦截做在**最底层**（`paint.js` 的落笔函数第一行就是 `isRoUnit(unit)`）——就算 UI 哪里漏了
  （快捷键、旧存档恢复的 unit），也写不进去。
- `⋯` 菜单里**没有「导出地形 PNG」**：编辑器不产出它，导出没有意义。
- 发现错格只能改管线的分类规则（`地图/栅格地形数据生成器/terrain.py` / `地图/栅格地形数据生成器/climate.py` / `地图/栅格地形数据生成器/display_class.py`）并重跑生成。

**编码**（`docs/adr/0006`、`0007`、`0010`；**逐条判定规则见 `docs/地形覆盖判定规格.md`**）：

```
地形 = 一个字节：高 **5** 位**覆盖**（20 值）0海洋 1淡湖 2河流 3冰川 ｜ 4密林 5疏林
       6灌丛 7草原 8草甸 9沼泽 10苔原 ｜ 11盐沼 12滩涂 ｜ 13沙质裸地 14砾质裸地 ｜ 15绿洲
       ｜ 16海冰 17咸湖 18盐漠 19火山（v9 追加）；
       低 **3** 位**形态**（4 值，只用 0–3）0平原 1丘陵 2高原 3山地
       （最大字节 31×8+3 = 251；海洋仍是覆盖 0 ∧ 形态 0 = 字节 0。⚠️ 覆盖顺序即契约；
       **0–3 钉死**——字节 0 判海陆、码 1/2/3 做细线保护）
气候 = 一个字节两轴：热量带（2 位）× 干湿（3 位），码 = 热量带×8 + 干湿（0..31；干湿 0 读作寒带）
显示类 = 覆盖 × 形态 × 气候，**地形即显示类**（88 类，`docs/adr/0008`、`0012`、`0014`）——密林／疏林（各按
       热量带与形态分）／灌丛／沙漠灌丛／苔原／高原草原／高山草原／亚寒带草原／亚热带草丛／
       荒漠·典型·草甸草原／稀树草原／热带·温带沙漠／热带·温带戈壁／寒漠／沙质裸地／砾质裸地／草甸／绿洲… **不存储**：
       名字是 地图/栅格地形数据生成器/display_class.py 的按轴词表算的（全函数），编辑器按 display_lut 查表
```

**显示类的两个契约键**（都从 `js/data.js` 来，由 `tools/editor_data.payload_from_meta()` 生成）：

```
display_classes = [{n: 名字, c: 颜色}] × 88        // 名字与配色的唯一出处
display_lut[((覆盖×4 + 形态)×32) + 码] = 类下标      // 2560 项（20 覆盖 × 4 形态 × 32 码），全覆盖
                                                   // 码 = 热量带×8+干湿；干湿 0 时整条码归零
                                                   // 长度由覆盖类数推出，**不写死**
```

**每个显示类都有独特色**：任意两类的 CIE Lab 色差 ΔE ≥ 9（实测最小 9.7），
由 `生成.py` 的契约断言与 `check_terrain` 的硬检查 0 守着。改配色看
`python 地图/栅格地形数据生成器/display_class.py` 的 ΔE 报告，别凭眼睛。

**海底不可落笔**：覆盖为「海洋」的像元，三个可编辑单元一律跳过（并在收笔时弹一句跳过格数）。
「海洋」就是全图的海陆口径（陆地 = NE 陆地 ∪ 湖泊 ∪ 冰川区），地块层在构建期已按它裁过，
所以"地块压在海上"不可能再发生；`import_editor.py` 也会再验一次。

## 图层与参考

`T` 地形底图 · `R` 参考（汉地唐州 / 其余单元边界）· `P` 地块线 · `K` 块区线。

**参考层**（`/数据/参考顶点.bin`）：**矢量顶点图**——**汉地是唐 741 州面**（Hartwell 339 州，
反投影后折回窗口），其覆盖区内整条被盖住的现代单元边界直接丢掉（不给两套线叠加）；
**其余地区是源数据的单元边界**（3682 个单元）。

为什么是矢量而不是栅格：老做法把边界烧成一张 8 位掩膜（`县界参考.png`），1px 线缩小就会
整片消失或闪烁，于是又得配一套 mipmap 金字塔来兜，而且"顶点"在栅格里根本读不出来。
现在线宽按**屏幕像素**给（`1 / 缩放`），缩到全图不糊、放大不粗；放大到 **12 倍**以上把原始
顶点落成小方块——对着顶点改地块本来就是这层的用途。

格式：`ZLRV1` 魔数 + 环表 + 格坐标 ×8 的 uint16 顶点对（1/8 格 ≈ 870 m），约 1 MB；
按需加载（第一次点「参考」时才取），失败只提示、不影响底图。

## 新建（按当前单元决定，落点 = 右键选中的那一格）

「＋ 新建」一个按钮，**建什么由当前单元决定**，不再有二级菜单：

| 当前单元 | 新建 | 落点要求 | 结果 |
|---|---|---|---|
| **地块** | 新建地块 | 先用**右键**在地图上选一格 | 那一格立刻归新地块（种子），接着用笔刷往外涂 |
| **块区** | 新建块区 | 先选中地块，再用右键选一格，**且该格必须在选中地块内** | 那一格归新块区，块区挂在该地块下 |
| **地域** | 不可新建 | — | 提示：地域是设计层固定的 93 个，用「地域」单元把地块指派进去 |
| **地形／气候** | 不可新建 | — | 提示：自然层由管线定稿，编辑器只读（`docs/adr/0001`） |

没选落点（或落点不合规）时不会静默失败，会提示"先用右键在地图上选一格"。撤销一步能同时回退"像元归属 + 新建的台账"。

## 右键 = 选中（不再是橡皮）

选中什么**由当前单元决定**：

| 单元 | 右键选中 | 说明 |
|---|---|---|
| **地域** | 光标下的**地块** | 地域的编辑对象本来就是地块 |
| **地块** | 那一**栅格** | 选中格记在 `selCell`，同时把该格所属地块设为当前地块 |
| **块区** | 那一**栅格** | 同时带上该格的地块与块区（切块区时会顺带把所属地块跟过去） |
| **地形／气候** | 不可选中 | 只读底图，没有"选中某个地形"这回事（点选看的是悬停贴里的那一格读数） |

按住右键拖动可连续拾取；视图模式下左右键都能点选。橡皮改由顶栏开关（`B` 笔 / `X` 橡皮）控制，不再占用右键。

## 飞地 / 多连通块检测

一个地块（或块区）的像元可能分成几块互不相连的部分——海岛、真实飞地，或者手滑涂远了：

- **单个对象**：右栏「连通块」一行给出块数；多于一块时列出每个碎块（格数 + `看` + `拆出`）。
  `拆出` 把那一块变成**新的地块/块区**（独立台账、自动命名"原名·碎块"），一步可撤销。
- **全图**：`⋯ → 飞地 / 多连通块检查` 弹出报告，列出所有多连通块对象（按碎块数排序，可一键跳过去），
  并附带**零像元台账**清单——种子台账里有、但栅格里一格都没落到的地块（小单元落在格心之间），
  可以「设为笔刷」手动画出来。地块清单里这类行也标着「空」。

> 边界线：**默认不画**。大色块本身已经说明了分界，全图边界线在最密的地方只会变成一层"毛边"。
> 需要时用顶栏 `地块线`(P) / `块区线`(K) 打开；真正的分界看**选中/悬停对象的轮廓**（自动描，1~2px，随缩放保持像素宽）。

## 数据模型：归属存在哪里

**真源是栅格**：每个像元写着一个地块编码 + 一个块区编码（`plot_id.png` / `dist_id.png`，`R+G×256`）。
"某个地块包含哪些像元"是从编码**反查**出来的（`cellsOf`），台账里**不存像元清单**：

| 存什么 | 放在哪 | 说明 |
|---|---|---|
| 几何 | 栅格像元的编码 | 唯一真源；并集、邻接、边界长度、连通块都由它派生 |
| 地块语义 | 台账 `plots[id] = {名称, 地缘, 地域}` | 只有语义，没有几何 |
| 块区语义 | 台账 `blocks[id] = {名称, 所属地块}` | "所属地块"是**声明式约束**：限定笔刷范围、判定越界 |

由此带来一个必然结果：地块被重新划分后，块区可能出现"**越界像元**"（像元所属地块变了，块区的声明没变）——
右栏会报数并可一键修正。这不是脏数据，而是"像元真源 + 声明约束"两套口径的正常摩擦。

## 操作一览

- 右键 = 选中（按单元决定选中地块还是栅格）｜ 单元 `1` 地域 ｜ `2` 地块 ｜ `3` 块区 ｜ `4` 地形 ｜ `5` 气候（**后两个仅视图模式**：只读）
- 模式 `V` 视图 ｜ `E` 编辑；笔 `B` ｜ 橡皮 `X`
- 半径 `[` `]` ｜ 清单里前后切换对象 `,` `.`（在自然层上则是**切换层**）｜ 适应窗口 `F` ｜ 取消选中 `Esc`
- 撤销 `Ctrl+Z` ｜ 重做 `Ctrl+Shift+Z` / `Ctrl+Y` ｜ 保存进度 `Ctrl+S`（浏览器本地）
- `⋯ → 存到待合入目录`：**正式交付**，落进 `地图/待合入/`，再由 `tools/import_editor.py` 合入真源
- 侧栏宽度可拖分隔条，布局记在 localStorage

```
js/config.js          常量、**三个可编辑单元**、调色、纯色函数、显示类查表（displayIndexOf 一次数组读）；
                      （只读自然层由 js/ro.js 注册进来）
js/ro.js              **只读自然层**（地形/气候）的统一描述与渲染：RO_LAYERS 一张表 —
                      取色 / 统计桶 / 左栏面板 / 右栏检视器 / 脚注，加一层只改这里
js/raster.js          像素容器：解码 PNG → TypedArray、各图层画布、边界掩膜与 mipmap
js/refvec.js          参考层：加载矢量顶点、按视野筛环（每环一个包围盒）
js/state.js           世界状态：地块/块区、归属台账、撤销栈（增量存档）、统计
js/render.js          视图：缩放平移、图层合成、掩膜金字塔、高亮、笔刷范围圈、页脚读数
js/paint.js           笔刷：圆形范围、笔/橡皮、三个可编辑单元的落笔规则（只读层在第一行就被拦掉）
js/ui.js              界面：模式/单元、SVG 控件、左右面板、检视器、存草稿、导入导出、键鼠
                       （对只读层只留三条通用路径：按钮由表生成、面板调 layer.panel、检视器调 layer.insp）
js/main.js            启动装配（含草稿探测与选择）+ window.__editor API
serve.py              本地服务：静态 + /数据/ 与 /草稿/ 虚拟挂载 + POST /保存（禁缓存）
启动编辑器.bat         双击即起服务并开浏览器
```

**这里没有 `data/` 了**——图只有一份真源（`地图/地图数据/栅格/`），编辑器由 `serve.py` 的
虚拟挂载去读它（`docs/adr/0002`）。编辑器自己的产出落 `地图/待合入/`。

依赖方向：`config → ro → raster → refvec → state → render → paint → ui → main`（无环）。
`ro` 只依赖 `config`（它把只读层注册回去），`raster`/`state`/`render`/`paint`/`ui` 都从 `ro` 取
"当前只读层怎么上色"——**谁也不许在别处按层名分叉**。

## 图层与编码

| 层 | 文件 | 编码 |
|---|---|---|
| 地块层 | `/数据/地块编码.png` | **24 位 RGB，地块编码 = R + G×256**，`0` = 无地块（海洋/未收录） |
| 块区层 | `/数据/分区编码.png` | **8 位灰度 = 地块内的局部序号**（1..255，`0` = 无块区）。全局 id 见台账 `districts` 的 `(plot, local)` |
| 地形层 | `/数据/地形编码.png` | 8 位灰度 = **覆盖(高 4 位) × 16 + 形态(低 4 位)**；图例 = `js/data.js` 的 `cover_legend`/`form_legend`。**只读** |
| 气候层 | `/数据/气候编码.png` | 8 位灰度 = **热量带 × 8 + 干湿**（0..31；干湿 0 读作寒带）。**只读** |
| 参考层 | `/数据/参考顶点.bin` | **矢量顶点**（环表 + 格坐标×8 的 uint16）。**汉地 = 唐 741 州面**，其余 = 源数据的单元边界（描图参考，非权威） |

地块层用 RGB 而非 16 位灰度，是因为 **canvas 会把 16 位灰度降成 8 位 RGBA、高字节丢失**（P社 `province.bmp` 同法）。
块区层与地形/气候层都是 8 位，够用（管线写 `L` 模式 PNG，编辑器导出的那张是 canvas 出的 RGBA，三通道同值）。

## 数据契约（给管线用）

- **几何真源** = 地块/块区编码 PNG，不是矢量。地块的并集、邻接、边界长度都由它派生。
- **语义** = 台账（`⋯ → 导出地块台账 CSV` / `导出块区台账 CSV`）：
  地块 `id, 名称, 地缘, 地域, 像元数, 估面积km²`；块区 `id, 名称, 所属地块, 像元数, 越界像元, 估面积km²`。
  运行时台账 `地图数据/栅格/台账.json` 的 `plots` 是 `{id, name, domain}`——`domain` 写**地域名**，
  它是编辑器唯一产出、管线唯一接收的语义字段（`import_editor.py` 合入时写回）。
- **存档** = 只记与构建基准的**增量**（改动像元 + 台账），因此可安全放进 localStorage；
  基准指纹里带了**地块名指纹**，换一批中文名即自动作废旧存档。
- 地形、海域、参考县界均为**静态底图**；**道路与通行代价不入栅格**（动态、稀疏，另用边表）。

## 重新生成

```bash
python tools/build_editor.py --dump-units      # 单元 + 种子地块（名字已全量中文化）
python 地图/栅格地形数据生成器/生成.py                   # 栅格 + 参考顶点 + js/data.js（编辑器要的那份）
python 地图/栅格地形数据生成器/check_terrain.py                  # 抽查地形：已知地点断言 + 地块不入海的自检
```

**编辑器改完的东西走另一条路合回去**：

```bash
python tools/import_editor.py --dry-run        # 只校验草稿（指纹 / 不压海洋 / 块区不越界 / 编号不重复）
python tools/import_editor.py                  # 校验 → 备份到 地图/待合入/备份-<时间戳>/ → 合入真源
```

`生成.py` **不再往编辑器拷图**（真源唯一，`docs/adr/0002`），也不再把编辑器当输出目录——
它只写 `地图编辑器/js/data.js`。两处生成 data.js 的代码收在 `地图/栅格地形数据生成器/editor_data.py`，
底图指纹的算法收在 `地图/栅格地形数据生成器/basetag.py`：**两处各写一份必然分叉**。

> 重跑 `生成.py` 会换掉底图指纹，于是**所有基于旧底图的草稿与浏览器增量存档一起作废**——
> 这是预期行为，不是 bug。草稿会被 `import_editor.py` 按指纹拒掉（提示"请重做"）。

默认栅格 **1/19°（≈ 5.86 km）→ 3819 × 2472 ≈ 944 万像元**（粗一档 `--cell 0.075`）。
地形需要 `原始数据/高程与地表/全球土地覆盖_100米.tif`（1.6 GB，Copernicus LC100）与
`全球高程_ETOPO_60秒.tif`、气候需要 `原始数据/气候/koppen_geiger_tif.zip`；`--no-veg` 可跳过土地覆盖。

数据目录在 `../地图数据/`（`原始数据/`、`基础单元.json`、`栅格/`、`运行态/`——目录与文件名都已中文化，
路径的唯一出处是 `../../地图/栅格地形数据生成器/mapdata.py`）；编辑器草稿在 `../待合入/`。
